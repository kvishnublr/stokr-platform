  - Next action timestamp

  - Filled quantity & percentage
  - Execution status, timestamp

  - Associated signal ID

  - Current price, market value
  - Current P&L (absolute & %)
  - Day's P&L, net P&L
  - Greeks (for options)
  - Risk metrics per position

Market Data:
  - Symbol, bid price, ask price
  - Bid volume, ask volume

  - Volatility metrics

Risk Metrics:
  - Total exposure value
  - Exposure as % of available
  - VaR (95%), VaR (99%)
  - Max drawdown limit
  - Current drawdown
  - Margin utilization %
  - Leverage ratio

System Health:
  - Service name, status
  - Instance count
  - CPU, memory utilization
  - Response time, error rate
  - Request throughput
  - Last health check time
