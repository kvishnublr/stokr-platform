 ADJUSTING FOR YOUR MARKET

If Too Many False Exits (Exits happening incorrectly):
  → Increase confidence threshold:
     UPDATE hybrid_exit_config SET parameters = '{"overbought": 75, "oversold": 25}'
     WHERE feature_name = 'indicator_rsi';

  → Require multiple signals:
     UPDATE hybrid_exit_config SET parameters = '{"min_signals": 2}'
     WHERE feature_name = 'dynamic_targets';

If Not Enough Exits (Positions stuck):
  → Lower overbought threshold:
     UPDATE hybrid_exit_config SET parameters = '{"overbought": 65, "oversold": 35}'
     WHERE feature_name = 'indicator_rsi';

  → Reduce confidence requirement:
     UPDATE hybrid_exit_config SET parameters = '{"confidence_threshold": 0.5}'
     WHERE feature_name = 'dynamic_targets';

If Exits Happening at Bad Prices:
  → Reduce volatility adjustment:
     UPDATE hybrid_exit_config SET parameters = '{"volatility_multiplier": 0.3}'
     WHERE feature_name = 'dynamic_targets';

  → Check: SELECT symbol, atr, original_target, dynamic_target FROM dynamic_targets;
