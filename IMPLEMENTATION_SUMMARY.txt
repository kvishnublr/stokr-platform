  Result: STILL FAILS

  Mode: BOTH (fallback from LIVE)
  Result: SUCCESS ✓
  Status: Order created and sent to ZERODHA
  Timestamp: 13:08:15

Outcome: Signal executed successfully via fallback mode
Signal Status: FILLED (in BOTH mode instead of LIVE)
Tracker Status: COMPLETED with 2 retries

If all retries fail: Signal marked as FAILED + flagged for manual intervention
